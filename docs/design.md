# 设计草稿

> 状态：brainstorming，随时改。

## 1. 背景

「三件好事」（Three Good Things / Three Blessings）是 Seligman 提出的感恩练习：每天睡前写下三件当天发生的好事，并说明它为什么让你开心。相关研究里，这类练习常用于提升幸福感。

这个仓库想把它做成一个真正天天愿意打开的小产品。

## 3. 形态对比

| 方案 | 优点 | 代价 | 适合 |
| --- | --- | --- | --- |
| Web / PWA | 跨平台、部署快、改动即时生效 | 推送和相册体验一般 | 先验证想法 |
| 手机 App（React Native / Flutter） | 体验最好、推送自然 | 打包上架成本高 | 长期产品 |
| 微信小程序 | 国内分享方便 | 审核、订阅消息限制 | 面向国内朋友 |
| 先不写代码（手账 / 表格） | 零成本 | 没提醒、没统计 | 先养成习惯 |

## 4. MVP 的最小样子（讨论用）

「能记三条 + 能看到过去 + 数据不丢」就够了。先自己用两周，再决定要不要提醒、统计、分享。
